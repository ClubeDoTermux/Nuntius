Comandos

Todos os comandos do chat e ferramentas do Nuntius

Chat Navegação

▼

/exit /quit /sair — Sai do chat

/help /ajuda — Mostra ajuda

/new /nova — Nova conversa

/clear /limpar — Limpa o console

/model — Mostra provedor e modelo ativos

/providers — Lista provedores disponíveis

Chat Memória & Aprendizado

▼

/search <termo> — Busca semântica em conversas passadas

/good /bom /ok — Marca interação como bem-sucedida

/bad /ruim /fail — Marca interação como mal-sucedida

/feedback /stats — Estatísticas de aprendizado

/history /historico — Histórico da conversa

/export — Exporta conversa em Markdown

Chat Skills & Plugins

▼

/skills — Lista skills aprendidas

/learn nome: instrução — Ensina uma skill manualmente

/forget nome — Remove uma skill

/plugins /plug — Lista plugins carregados

/mcp — Status dos servidores MCP

Chat Sistema

▼

/cache — Mostra status do cache de ferramentas

/cache clear — Limpa cache

/scheduled /tasks /cron — Lista tarefas agendadas no cron

/stats — Estatísticas da sessão

Ferramentas Arquivos & Shell

▼

read — Lê arquivo

write — Escreve arquivo

edit — Edita arquivo (substituição exata)

glob — Busca arquivos por padrão

grep — Busca conteúdo em arquivos

run_shell bash — Executa comando shell

run_python — Executa código Python

run_node — Executa JavaScript/Node.js

run_go — Executa código Go

run_rust — Executa código Rust

Ferramentas Web & GitHub

▼

web_search — Pesquisa na web

web_fetch — Obtém conteúdo de URL

browser_open — Abre URL em navegador headless (com JS)

browser_screenshot — Captura screenshot de página

task — Delega tarefa a subagente

github_* — Ferramentas GitHub (listar repos, issues)

drive_* — Ferramentas Google Drive (listar, baixar)

Ferramentas Agendamento

▼

schedule_task(cron, command, task_id) — Agenda tarefa no cron do sistema

schedule_task(cron="0 9 * * *", command="echo Bom dia!", task_id="saudacao")

list_scheduled_tasks() — Lista tarefas agendadas

remove_scheduled_task(task_id) — Remove tarefa

clear_scheduled_tasks() — Remove todas as tarefas Nuntius

Ferramentas Subagentes & Orquestração

▼

delegate(task, role, tools) — Delega tarefa a subagente isolado

delegate(task="Crie um script Python para backup", role="code")
delegate(task="Pesquise sobre API do GitHub", role="search", tools=["web_search", "web_fetch"])

list_subagents() — Lista subagentes ativos e status

/subagents /agents — Lista subagentes no chat

Roles nativas: code shell search writer debug

Cada subagente tem contexto isolado, system prompt próprio e conjunto limitado de ferramentas.

Ferramentas Utilitárias

▼

current_time — Data e hora atuais

calculator — Calculadora

system_info — Informações do sistema

random_number — Número aleatório

random_uuid — UUID v4

random_password — Senha aleatória

Instalação

Funciona no Linux, Termux e macOS

1

Instalar via pip

Requer Python 3.8+ e pip

pip install git+https://github.com/ClubeDoTermux/Nuntius.git
2

Configurar

Execute nuntius setup para configurar seu provedor e chave de API

3

Usar

Digite nuntius no terminal para iniciar o chat
